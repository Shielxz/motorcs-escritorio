# Motor CS — app de escritorio (instaladores)

Este repositorio solo publica los **instaladores** de la app de escritorio de Motor CS para Windows.
No contiene código ni datos del sistema.

- **Descargar la versión más reciente:** [Motor-CS-Setup.exe](https://github.com/Shielxz/motorcs-escritorio/releases/latest/download/Motor-CS-Setup.exe)
- La app se actualiza sola: consulta `https://evans-motor.com/descargas/escritorio/version.json` y descarga el instalador desde aquí.
